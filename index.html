fall-palette

Ctrl+K command palette · drop-in plugin · zero dependencies

This page is a live demo. Press Ctrl K (or ⌘K on Mac) right now.

What it does

◊

Auto-discovers

Every nav button and clickable action in the host page is found and listed automatically. No config needed.

/

Fuzzy search

Subsequence match · type any partial like opfq to hit "Open RFQs". Sorted by relevance.

⌨

Keyboard native

Ctrl+K opens · ↑↓ navigate · Enter to fire · Esc to close. Tab cycles too. Mouse works if you want.

+

Programmable

Register custom commands from your tool with window.fallPalette.register({label, run}).

Install · one line

<script src="https://sjgant80-hub.github.io/fall-palette/fall-palette.js" defer></script>

Drop that anywhere before </body>. Ctrl+K works on next page load. No build step, no npm, no framework.

Register custom commands

window.fallPalette.register({
  id:       'sweep:135',                       // unique key
  label:    'Sweep BTC to primed wallet',      // shown in palette
  group:    'Sweep',                           // category column
  keywords: 'broadcast tx send bitcoin',       // extra search match
  run:      () => window.fastSweep(privKey)    // fired on Enter
});

Estate-aware

Detects other Fall* shims if loaded and surfaces their actions:

  • window.bloom → "Decompose text (bloom signature)"
  • window.apexSync → Export · Import · Configure sync endpoint
  • window.kcc → respects .dev-mode body class

API

window.fallPalette.open()             // open programmatically
window.fallPalette.close()
window.fallPalette.register(cmd)      // {id?, label, group?, keywords?, run}
window.fallPalette.discover()         // return current command list
